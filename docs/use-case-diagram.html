Multi-Stage Approval Flow
A reservation progresses through configurable stages before reaching APPROVED or DECLINED:
  1. Office User submits reservation → status: PENDING
  2. VP-level officers (VPAA / VPSAS / VPAF / VPRDE) review if required
  3. Campus Director endorses or approves at final stage
  4. Admin can approve or decline at any stage
  5. Each action is logged and triggers a notification to the requestor
